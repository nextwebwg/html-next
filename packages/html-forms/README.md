# `@nextwebwg/html-forms`

Reference implementation for the [HTML Forms proposal](https://nextwebwg.org/html-forms/).
It builds requests from native forms and submitters, preserving successful-control,
validation, encoding, and cancellation semantics.

The API accepts native DOM objects and has no dependency on Declarative HTML Components.
The package is MIT-licensed, experimental, and remains private pending the repository's
visibility and publication decisions.
